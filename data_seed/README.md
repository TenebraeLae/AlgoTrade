# data_seed — фолбэк-данные

Заполняется агентом при отсутствии доступа к официальному источнику. Любая строка здесь
без подтверждения источником помечена `TODO(VERIFY)` и не используется для live-решений.

| Файл | Назначение | Когда использовать |
|---|---|---|
| `holidays_ru.md` | праздничные нерабочие дни MOEX | только если API не отдаёт календарь; иначе — API |
| `sectors.md` | отраслевая классификация для лимита «≤2 в секторе» | только если API не отдаёт сектор инструмента |

Правило: приоритет у живого источника (API брокера). `data_seed` — страховка от
«не получили данные», а не источник истины. Расхождение с API → берём API, пишем WARNING.
