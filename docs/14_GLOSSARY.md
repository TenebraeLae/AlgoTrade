# 14_GLOSSARY — единая терминология

Разнобой в терминах порождает баги: «позиция» в одном модуле — открытая сделка,
в другом — заявка. Используй только эти определения, имена сущностей в коде — те же.

| Термин | Определение | Имя в коде |
|---|---|---|
| Инструмент | Биржевой объект: uid, лот, квант, статус | `InstrumentInfo` |
| Тикер | Человекочитаемый код инструмента | `ticker` |
| Квант | Минимальный шаг цены | `min_price_increment` |
| Лот | Целая единица объёма заявки | `lot_size` |
| Свеча | Закрытый бар OHLCV; незакрытая свеча — не данные | `Candle` |
| Сигнал | Гипотеза входа после индикаторов, до риска | `Signal` |
| Вердикт риска | Разрешение/запрет и максимальный объём | `RiskVerdict` |
| Заявка | То, что уходит брокеру (или эмулируется) | `OrderRequest` |
| Сделка | Факт исполнения (часть или целое), одна строка в БД | `Trade` |
| Позиция | Совокупность сделок по тикеру с止опом/тейком | `Position` |
| Journal (решение) | Полный контекст момента решения | `Decision` |
| Режим рынка | trending / ranging / transitional / chaos | `regime` |
| Ветвка стратегии | trending-тренд, ranging-mean-reversion | `branch` |
| Просадка дневная | Потеря с начала сессии | `daily_loss` |
| Просадка общая | Макс. падение относительно пика с запуска | `max_drawdown` |
| Альфа | Доходность бота минус доходность IMOEX | `alpha` |
| Paper / Live | Режим эмуляции / режим реальных заявок | `TRADING_MODE` |
| Orphan | Позиция на бирже, невосстановленная локально | `source=orphan` |
| Kill switch | Экстренное закрытие всего | `panic()` |
| Вес комбинации | Коэффициент влияния комбинации индикаторов | `weight` |
| Proposal | Предложение L3, ожидающее ручного подтверждения | `Proposal` |
| Откат | Возврат к backup-набору параметров | `rollback` |
| Сессия | 10:00–23:50 МСК основного рынка MOEX | `trading_session` |
| Аукцион | Открытие 09:50–10:00, закрытие 23:40–23:50, не для сделок | `auction` |
| Grep-правило | Линтер-запрет (float в деньгах, наивный now) | `ci` |

## Чего не говорить/не писать

- «Бот заработал» — неоперационно. Говори P&L, win-rate, альфа.
- «Стратегия прибыльная» — без периода, выборки и сравнения с индексом не произноси.
- «Стоп-лосс сработал» — уточняй: биржевой или локально-эмулируемый.
- «Цена» — указывай валюту и квант.
- «Мини-просадка»/«небольшой убыток» — только с числом в %.

## Числовые соглашения

Валюта ₽ с разделителями тысяч. Проценты — 2 знака, всегда со знаком. Время — МСК
в отображении, UTC в хранилище, формат `YYYY-MM-DD HH:MM:SS`. Объём — лоты (не штуки акций).
