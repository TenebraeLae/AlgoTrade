# TBot Handoff Package

Коробка документов для **ИИ-агента-разработчика**, который будет писать торгового бота
для Т-Инвестиций по спецификации. Человек здесь — оператор: он подтверждает решения,
агент выполняет работу и отчитывается.

## Из чего состоит пакет

| Файл | Кто читает | Назначение |
|---|---|---|
| `AGENTS.md` | агент | Регламент работы. Обязателен к исполнению в каждой сессии. |
| `CHANGELOG_AI.md` | агент | Журнал, который агент ведёт сам. Обязан заполнять каждый шаг. |
| `docs/00_PLAN.md` | агент | Продуктовая спецификация. Источник истины по «что». |
| `docs/01..15_*.md` | агент | Детализация: архитектура, правила кода, стратегия, риск, БД, API, деплой, приёмка. |
| `tasks/MILESTONES.md` | агент + оператор | Порядок этапов и обоснование. |
| `tasks/BACKLOG.md` | агент | Задачи с чекбоксами. Агент отмечает только реально сделанное. |
| `prompts/SESSION_PROMPTS.md` | оператор | Готовые промты для начала и коррекции работы. |
| `templates/*` | агент | Dockerfile, compose, конфиги, requirements — стартовые скелеты. |
| `data_seed/*` | агент | Фолбэк-данные (календарь, секторы) с пометками TODO. |

## Порядок работы оператора

1. Отдать агенту `AGENTS.md` первым и потребовать подтвердить, что он его принял.
2. Дать `docs/00_PLAN.md` + `docs/01_ARCHITECTURE.md` + `tasks/MILESTONES.md`.
3. Работать по этапам: один этап за сессию. Промты — в `prompts/SESSION_PROMPTS.md`.
4. После каждого этапа проверять по `docs/15_ACCEPTANCE.md`. Не принято — не идём дальше.
5. Читать `CHANGELOG_AI.md`. Если шага там нет — работа не засчитывается.

## Три красные линии

1. **Live-режим не включается кодом.** Только человек меняет флаг вручную.
2. **Риск-менеджер не имеет интерфейса для увеличения риска.** Ни из бота, ни из VK.
3. **Любой вызов T-Invest API, не подтверждённый документацией или SDK, помечается `TODO(VERIFY)` и не считается готовым.**

## Ожидаемый результат

Docker-образ, который поднимается одной командой, просит токен, стартует в paper-режиме,
показывает дашборд, шлёт уведомления в VK и ведёт полный журнал решений.
