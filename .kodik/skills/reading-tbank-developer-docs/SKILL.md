# Чтение документации T-Bank

Для любого URL `https://developer.tbank.ru/*` сначала прочитай **`docs/TBANK_HTTPS.md` от корня текущего репозитория**. Это обязательный runbook доступа, а не копия документации API. Не подменяй им содержимое запрошенной страницы.

## Порядок действий

1. До первого сетевого запроса прочитай `docs/TBANK_HTTPS.md`. Не начинай с `web_fetch`: для этого домена уже подтверждена ошибка доверия сертификату. `Agent network error` сам по себе не доказывает причину новой ошибки.
2. Используй PowerShell-блок «Проверенное чтение страницы» из документа, выполняя его из корня репозитория через доступный shell. Замени только переменную `url` на нужный HTTPS-адрес с точным hostname `developer.tbank.ru`; путь и query сохрани. Для других доменов этот навык не применяется.
3. До отправки запроса проверь локальный `.tls-verify/Russian_Trusted_Root_CA.pem` по SHA-256 DER, указанному в документе. Сохрани стандартные CA, добавь корень только в отдельный `SSLContext`; `check_hostname=True` и `CERT_REQUIRED` обязательны.
4. Если документа, Python, сертификата или shell нет, отпечаток не совпал либо TLS-проверка не прошла — останови этот путь и сообщи конкретный блокер. Не извлекай доверенный корень из недоверенной серверной цепочки. В рамках этого навыка не скачивай и не перезаписывай файл CA: получение или замена корня требуют отдельной согласованной задачи.
5. Проверь фактические HTTP status, конечный URL и содержимое нужной страницы. Ошибку сети, HTTP или пустой/неподходящий ответ не выдавай за успешное чтение. Если вывод усечён, получи нужный фрагмент перед выводами.
6. В ответе ссылайся на исходный URL и различай свежепрочитанные сведения и исторические наблюдения из runbook. При недоступности страницы не выдумывай методы SDK, поля или текущие лимиты.

## Частые ошибки

| Ошибка | Правильное действие |
| --- | --- |
| Повторять `web_fetch` после настройки Python | У процессов разные хранилища доверия; используй отдельный Python-контекст. |
| Отключать TLS ради чтения | Запрещены `verify=False`, `CERT_NONE`, `--insecure` и глобальная подмена SSL-контекста. |
| Импортировать CA в Windows или менять окружение бота | Для чтения документации это не требуется и не разрешается этим навыком. |
| Считать старые числа из runbook актуальной квотой | Прочитай нужную страницу; опубликованный лимит не равен измеренной персональной квоте. |

Ни токены, ни keyring, ни запуск бота для этого чтения не нужны. Навык не исправляет доверие встроенного `web_fetch` или браузера и не предоставляет дополнительных разрешений инструментам.
